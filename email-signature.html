Como instalar no Gmail
  1. Abra este arquivo no navegador.
  2. Selecione o bloco da assinatura (do "timelabs" até a linha de confidencialidade).
  3. Copie (Ctrl+C).
  4. No Gmail: ⚙ Configurações → Ver todas as configurações → aba "Geral" → seção "Assinatura".
  5. Crie uma nova assinatura, cole (Ctrl+V).
  6. Salve no fim da página.
Como instalar no Outlook (desktop)
  1. Abra este arquivo no navegador.
  2. Selecione e copie o bloco da assinatura.
  3. No Outlook: Arquivo → Opções → E-mail → Assinaturas.
  4. Crie uma nova assinatura e cole no editor.
  5. Defina como padrão para novos e-mails / respostas, se desejar.
